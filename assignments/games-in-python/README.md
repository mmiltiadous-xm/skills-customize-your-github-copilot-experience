# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build a classic Hangman game in Python using strings, loops, conditionals, and user input. By the end, you will create a complete playable game with clear win and lose outcomes.

## 📝 Tasks

### 🛠️	Build the Core Hangman Game

#### Description
Create the main game loop for Hangman. The program should pick a word from a predefined list and let the player guess one letter at a time.

#### Requirements
Completed program should:

- Randomly select a word from a predefined list.
- Accept single-letter guesses from the player.
- Display current word progress using underscores for missing letters (for example: `_ _ _ _`).
- Track and display the number of incorrect guesses remaining.


### 🛠️	Finish Game Outcomes and Messages

#### Description
Add game-ending conditions and user feedback so the player knows whether they won or lost.

#### Requirements
Completed program should:

- End the game when the word is fully guessed.
- End the game when all attempts are used.
- Display a clear win message when the player guesses the word.
- Display a clear lose message and reveal the correct word when attempts are exhausted.
